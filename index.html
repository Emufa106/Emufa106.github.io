Personal archival application

Personal Drive Backup

Personal Drive Backup is a personal application operated by its account owner. It is designed to save backup ZIP archives from a private GitHub Actions workflow into an existing, authorized Google Drive folder.

How the backup works

The workflow packages selected files, checks the destination folder, creates a new backup archive, and downloads that archive again. It compares the downloaded bytes, SHA-256 digest, ZIP inventory and individual file hashes to verify the backup.

The archival implementation does not overwrite or delete existing Drive files or change their sharing permissions. A matching existing backup is reused only after verification.

Why Google Drive access is requested

Drive access allows the workflow to read destination-folder and archive metadata, create backup ZIP files in the designated folder, and download those archives for integrity checks. The current integration requests the full Google Drive OAuth scope because it accesses a pre-existing folder without a file-picker authorization flow.

The Google permission grant is broader than one folder: it can permit access to all Drive files available to the authorizing account. The application's implemented archival operations are limited to the designated backup destination and matching archives. The scope itself does not enforce that folder boundary.

Personal use and privacy

This application is for its operator's personal backups. This information website does not offer sign-in, request credentials, or publish files or backup contents.
